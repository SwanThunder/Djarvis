# Проверки выполнимости — 2026-11-04

[English version](FEASIBILITY.md) · [Решения](DECISIONS.ru.md) · [Статус](../STATUS.ru.md)

Статус: замеры PLAN-021 и PLAN-022 (раздел 4), выполненные с согласия владельца на его рабочем ПК. Это ранние данные для выбора архитектуры, а не результаты приёмки на целевой машине с 8 ГиБ. Кода продукта не писалось. Рабочие файлы остаются в игнорируемой папке `cache/feasibility/`.

## 1. Тестовая машина

Intel Core i5-12400F (6 ядер / 12 потоков), 31,8 ГиБ ОЗУ, NVIDIA RTX 5060 Ti, Windows 11, Python 3.12.10. Видеокарта в тестах моделей отключалась; объёмы памяти приведены для сравнения с целью 8 ГиБ. Типичный процессор ноутбука с 8 ГиБ будет медленнее этого настольного.

## 3. Выводы, влияющие на проект

1. **Память на 8 ГиБ впритык.** Модель ≈ 3,0 ГБ + оба речевых движка ≈ 1,05 ГБ + PostgreSQL ≈ 0,2 ГБ + ядро и интерфейс + Windows почти не оставляют запаса; распознавание речи ещё не замерено. Профиль 8 ГиБ должен загружать только движок речи текущего языка, выгружать модель после простоя и иметь вариант меньшей модели.
2. **Скорость генерации.** Около 11 токенов/с на этом процессоре означает примерно 5–8 токенов/с на слабых ноутбуках; ответы нужно передавать в синтез по предложениям.
3. **Нормализация текста перед речью.** Vosk 0.7 падает на символах вне своей таблицы фонем (например, «»). Перед синтезом текст должен очищаться, а ошибка синтеза никогда не должна останавливать диалог.
4. **Зависимость под GPL.** kokoro-onnx устанавливает `espeakng-loader`, который содержит espeak-ng (GPL). Нужно проверить способ поставки или использовать фонемизатор английского не под GPL.
5. **Версия модели Vosk.** 0.7 помечена устаревшей; актуальная 0.9 multi весит 746 МБ. Качество против размера нужно оценить на слух.
6. **Управление процессами.** `pg_ctl start` держит открытыми унаследованные дескрипторы вывода; хост, ожидающий вывода через канал, зависает. Ядро должно запускать PostgreSQL с выводом в файлы и проверять готовность отдельно (как `pg_isready`).
7. **Права на папку данных.** Папка, созданная на диске F:, унаследовала доступ для локальной группы «Пользователи». При инициализации нужно задавать явные права только для владельца (ADR-014).
8. **Независимость среды модели.** Вызов консольной утилиты установленной среды запустил её настольное приложение. Продукт должен поставлять и контролировать собственную среду модели и не зависеть от среды, установленной пользователем отдельно, и не запускать её.

## 4. Распознавание речи, ключевая фраза, Vosk 0.9 и фонемизатор (PLAN-022)

Та же машина, только CPU. Тестовый корпус синтетический: 12 русских фраз × 3 голоса Vosk TTS × 2 версии модели и 6 английских фраз × 3 голоса Kokoro. Каждая фраза чистая и с розовым шумом 10 дБ, всего 180 записей по 16 кГц. Половина фраз начинается с имени персонажа, половина — без имени, с похожими словами («новую», «новости», «вольт», «Эдуард», «Edwin», «volts»). Скрипты и результаты лежат в `cache/feasibility/` (`asr_*.py`, `wake_*.py`, `results/`).

### 4.1 Распознавание реплики

WER — доля ошибочных слов; числа приведены к словам. Коэффициент реального времени (RTF) — время обработки, делённое на длительность звука.

| Движок | Память процесса | WER ru (голоса 0.9 / 0.7) | WER en | RTF |
| --- | --- | --- | --- | --- |
| Vosk small ru 0.22 / en 0.15, поток кусками по 250 мс | ≈ 0,18–0,23 ГБ | 5,1–5,5 % / 11–14 % | 2–8 % | ≈ 0,16–0,24 |
| Whisper base int8 | ≈ 0,2 ГБ, пик 0,35 | 9,7 % / 22 % | 0–6 % | ≈ 0,12 |
| Whisper small int8 | ≈ 0,4 ГБ, пик 0,73 | 4,6–5,9 % / 16–17 % | 0–2 % | ≈ 0,28–0,36 |

Голоса Vosk 0.7 разборчивы хуже, чем 0.9, поэтому строка «0.7» оценивает скорее синтез, чем распознавание. Шум 10 дБ ухудшает результат слабо. Whisper не даёт потоковых промежуточных результатов и путает «Нова» с «Ново».

### 4.2 Ключевая фраза

| Способ | ru: найдено / ложно | en: найдено / ложно | RTF |
| --- | --- | --- | --- |
| Vosk small, грамматика только из имён | 72/72 / 68/72 | 18/18 / 6/18 | ≈ 0,016 |
| Vosk small, полный словарь, имя как отдельное слово | 55/72 / 2/72 | 15/18 / 0/18 | ≈ 0,16 |
| **Vosk small, грамматика из имён и слов-приманок** | **68/72 / 3/72** | **18/18 / 1/18** | **≈ 0,018** |

Все оставшиеся ложные срабатывания — имя в середине фразы («…напомни Эдвард»). Их отсекает правило «имя засчитывается только в начале реплики после паузы». Пропуски — «Нова», услышанная как «ново», в одном голосе. Уверенность распознавателя ложные срабатывания не отделяет: у них она тоже около 1,0. Часть приманок подобрана под этот корпус, поэтому цифры оптимистичны. Своя фраза пользователя работает, если её слова есть в словаре модели; это можно проверить при вводе.

### 4.3 Vosk TTS 0.9 против 0.7

| Модель | Загрузка | Память, пик | RTF | Символы «» |
| --- | --- | --- | --- | --- |
| 0.7 multi (129 МБ) | ≈ 7 с | 0,75 ГБ | ≈ 0,05 | падает (KeyError) |
| 0.9 multi (746 МБ, распаковано 894 МБ) | ≈ 124 с | 1,48 ГБ, пик 1,84 | ≈ 0,22–0,25 | падает (KeyError) |

Для 0.9 почти всё время загрузки уходит на создание сессии onnxruntime для основной модели (171 МБ). Отключение оптимизаций и предварительно сохранённый оптимизированный граф не помогают; перевести модель в формат `.ort` не удалось. Примеры для прослушивания: `cache/feasibility/samples/vosk09_ru_spk0…4_*.wav` рядом с `vosk07_ru_spk0…4_*.wav`.

### 4.4 Английский фонемизатор без GPL

misaki 0.9.4 (Apache-2.0) со словарями и spaCy `en_core_web_sm`, без запасного espeak-ng (`fallback=None`). Модули espeak и phonemizer не загружались. Обычные слова покрыты полностью. Без фонем остались незнакомые имена (Tavily, Kubernetes, Djarvis) и время вида «3:45». Kokoro принял фонемы напрямую (`is_phonemes=True`): Whisper small распознал четыре проверочные фразы без смысловых ошибок. Примеры: `samples/kokoro_misaki_noespeak_*.wav`.

### 4.5 Выводы

9. **Распознавание:** Vosk small для обоих языков. Одна загруженная модель обслуживает и ключевую фразу (грамматика с приманками), и реплику (полный словарь, поток); вместе ≈ 0,2 ГБ. Whisper small годится как второй, более точный проход только в профилях с запасом памяти; Whisper base для русского не подходит.
10. **Ключевая фраза:** грамматика с приманками плюс правило «только в начале реплики». После пробуждения реплика всё равно проходит полное распознавание; пустая или бессмысленная реплика молча возвращает ожидание.
11. **Vosk 0.9 не для 8 ГиБ:** вдвое больше памяти, в 5 раз медленнее, около 2 минут загрузки. Остаётся 0.7 с обязательной очисткой текста; 0.9 — возможный голос повышенного качества для машин с 16 ГиБ, если владельцу понравится звучание и загрузку удастся ускорить.
12. **GPL снимается:** английская цепочка misaki → Kokoro работает без espeak-ng. Нужны свой словарь терминов (имена персонажей, названия сервисов), нормализация чисел и времени перед синтезом, а для незнакомых слов — произнесение по буквам. Пакет kokoro-onnx (MIT) тянет `espeakng-loader` как зависимость; продукт использует тонкую собственную обёртку над ONNX-моделью или ставит пакет без этой зависимости.

## 5. Пока не проверено

Живой микрофон и реальная комната (подготовлен `cache/feasibility/mic_wake_test.py`: звук только в памяти, на диск не пишется); реальная машина с 8 ГиБ только на CPU; память интерфейса Flutter; установщик и подпись; миграции базы; стабильность в длительной сессии; эхо собственного голоса ассистента.
