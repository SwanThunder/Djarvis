# Проверки выполнимости — 2026-11-04

[English version](FEASIBILITY.md) · [Решения](DECISIONS.ru.md) · [Статус](../STATUS.ru.md)

Статус: замеры PLAN-021, выполненные с согласия владельца на его рабочем ПК. Это ранние данные для выбора архитектуры, а не результаты приёмки на целевой машине с 8 ГиБ. Кода продукта не писалось. Рабочие файлы остаются в игнорируемой папке `cache/feasibility/`.

## 1. Тестовая машина

Intel Core i5-12400F (6 ядер / 12 потоков), 31,8 ГиБ ОЗУ, NVIDIA RTX 5060 Ti, Windows 11, Python 3.12.10. Видеокарта в тестах моделей отключалась; объёмы памяти приведены для сравнения с целью 8 ГиБ. Типичный процессор ноутбука с 8 ГиБ будет медленнее этого настольного.

## 3. Выводы, влияющие на проект

1. **Память на 8 ГиБ впритык.** Модель ≈ 3,0 ГБ + оба речевых движка ≈ 1,05 ГБ + PostgreSQL ≈ 0,2 ГБ + ядро и интерфейс + Windows почти не оставляют запаса; распознавание речи ещё не замерено. Профиль 8 ГиБ должен загружать только движок речи текущего языка, выгружать модель после простоя и иметь вариант меньшей модели.
2. **Скорость генерации.** Около 11 токенов/с на этом процессоре означает примерно 5–8 токенов/с на слабых ноутбуках; ответы нужно передавать в синтез по предложениям.
3. **Нормализация текста перед речью.** Vosk 0.7 падает на символах вне своей таблицы фонем (например, «»). Перед синтезом текст должен очищаться, а ошибка синтеза никогда не должна останавливать диалог.
4. **Зависимость под GPL.** kokoro-onnx устанавливает `espeakng-loader`, который содержит espeak-ng (GPL). Нужно проверить способ поставки или использовать фонемизатор английского не под GPL.
5. **Версия модели Vosk.** 0.7 помечена устаревшей; актуальная 0.9 multi весит 746 МБ. Качество против размера нужно оценить на слух.
6. **Управление процессами.** `pg_ctl start` держит открытыми унаследованные дескрипторы вывода; хост, ожидающий вывода через канал, зависает. Ядро должно запускать PostgreSQL с выводом в файлы и проверять готовность отдельно (как `pg_isready`).
7. **Права на папку данных.** Папка, созданная на диске F:, унаследовала доступ для локальной группы «Пользователи». При инициализации нужно задавать явные права только для владельца (ADR-014).
8. **Независимость среды модели.** Вызов консольной утилиты установленной среды запустил её настольное приложение. Продукт должен поставлять и контролировать собственную среду модели и не зависеть от среды, установленной пользователем отдельно, и не запускать её.

## 4. Пока не проверено

Распознавание речи и wake-фразы; реальная машина с 8 ГиБ только на CPU; память интерфейса Flutter; установщик и подпись; миграции базы; стабильность в длительной сессии.
