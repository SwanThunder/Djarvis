# Оценка локальной модели

[English version](LOCAL_MODEL.md)

Дата: 2026-11-03. Статус: скачана, контрольная сумма проверена, модель зарегистрирована, первичные проверки ответов пройдены. Это подготовка окружения для оценки, а не выбор окончательной архитектуры приложения или разрешение программирования.

## Кандидат и происхождение

- Базовая модель: Qwen3.5 4B.
- Квантование: Unsloth GGUF, Q4_K_M.
- Репозиторий квантования: `unsloth/Qwen3.5-4B-GGUF`.
- Закреплённая версия: `e87f176479d0855a907a41277aca2f8ee7a09523`.
- Файл: `Qwen3.5-4B-Q4_K_M.gguf`, 2 740 937 888 байт.
- Проверенный SHA-256: `00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4`.
- В исходной модели и репозитории квантования указана лицензия Apache-2.0. Исходная лицензия включена в локальные метаданные модели движка. Для распространения продукта ещё нужны соответствующие уведомления и проверка полного набора зависимостей.

## Локальное окружение

- Уже установленный движок: Ollama 0.40.13; дополнительный движок инференса не устанавливался.
- Локальное имя: `djarvis-qwen3.5-4b:latest`.
- Контекст проверки: 4096 токенов; температура 0.3 в локальной конфигурации модели.
- Компьютер разработки: Intel Core i5-12400F, примерно 32 ГиБ ОЗУ, NVIDIA RTX 5060 Ti с 8 ГиБ видеопамяти.
- По данным локального движка модель полностью загружена в видеопамять; сообщаемое выделение — примерно 3,0 ГБ при контексте 4096 токенов.

Кандидат 4B выбран с запасом памяти на этом компьютере. Наблюдения не определяют минимальные требования покупателей и не обещают скорость на другом оборудовании.

## Загрузка и хранение

Штатная загрузка из реестра завершилась ошибкой TLS. Альтернативный путь: GGUF закреплённой версии скачан по проверяемому HTTPS из репозитория квантовщика на Hugging Face, размер и SHA-256 сверены с метаданными репозитория, затем файл импортирован установленным движком. Проверка TLS-сертификатов не отключалась.

Скачанный файл и конфигурация локальной проверки находятся в `cache/model-downloads/`, исключённой из Git. Движок также хранит импортированную модель вне проекта. Существующие модели сохранены. В коммит документации не включаются веса, образцы голосов, учётные данные, аппаратные серийные номера и идентификаторы пробного периода.

## Проверки

Метаданные показывают семейство `qwen35`, квантование Q4_K_M и возможности генерации, рассуждений и инструментов. Локальные метаданные модели содержат лицензию Apache-2.0. Пройдены три синтетические проверки с отключённым режимом рассуждений и контекстом 4096 токенов:

| Проверка | Наблюдаемый результат | Полное время запроса | Время генерации |
| --- | --- | --- | --- |
| Разговор на русском, первая инициализация | Связное русское предложение о планировании | 85,49 с | 1,59 с |
| Разговор на английском, прогретая модель | Связное английское предложение о планировании | 0,38 с | 0,26 с |
| Предложение задачи на русском, прогретая модель | Один вызов `propose_task` с `Купить молоко`, `2026-11-04` и `18:00` | 1,34 с | 0,59 с |

Настоящий инструмент не выполнялся. Аргументы синтетического вызова совпали с указанными названием, датой и временем. Короткие проверки не подтверждают общее языковое качество или надёжность самостоятельных действий. Большую задержку первой инициализации нужно изучить до определения целевых показателей продукта. Исходные синтетические ответы остаются в исключённом кэше. После оценки модель выгружена из видеопамяти; на диске она остаётся установленной.

Все запросы инференса при оценке направлялись к локальному API `127.0.0.1:11434`; обращения к облачному API инференса не выполнялись. Для загрузки использовался интернет. Настоящие задачи и файлы пользователя синтетические проверки не меняли. Это описание выполненных запросов, а не полный аудит сетевой изоляции установленного движка.

## Использование и ограничения

Запуск установленного кандидата: `ollama run djarvis-qwen3.5-4b`.

Языковая модель не устанавливает распознавание и синтез речи, движок ключевой фразы, подключения погоды/поиска, защиту подписки или интерфейс приложения. Это отдельные вопросы проектирования. До окончательного выбора нужны более широкая оценка языкового качества, надёжности инструментов, задержек, памяти совместно с голосовыми моделями и работы на слабом оборудовании.
