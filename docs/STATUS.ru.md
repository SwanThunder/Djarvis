## 1. Общее состояние

- Этап: проектирование. Кода приложения нет, программирование не разрешено.
- Готово: требования к продукту, обязательный визуальный дизайн (плюс локальные брифы v2.1 и компоновки v1.0), шестнадцать узких ADR и подробные предложения по всем 20 компонентам (CP01–CP20).
- Выполнимость (PLAN-021): локальная модель, синтез речи, собственный PostgreSQL и встроенный Python работают на CPU; память 8 ГиБ впритык — см. [проверки выполнимости](architecture/FEASIBILITY.ru.md).
- Распознавание (PLAN-022): Vosk small для ключевой фразы и реплики (≈ 0,2 ГБ, WER ≈ 5 % на синтетике); ключевая фраза — грамматика с приманками и правило «только в начале реплики»; Vosk TTS 0.9 слишком тяжела для 8 ГиБ; английский синтез работает без espeak-ng (GPL).
- Подготовлены на утверждение: [технические детали](architecture/TECHNICAL_DESIGN.ru.md) и [финальная архитектура и план реализации](architecture/IMPLEMENTATION_PLAN.ru.md).
- Технические решения T1–T6 утверждены (ADR-015); план реализации на чтении у владельца.
- Структура проработана (PLAN-024): [схема базы](architecture/SCHEMA.ru.md) (45 таблиц), [каталог API](architecture/API.ru.md), [модули](architecture/MODULES.ru.md); вопросы В1–В5 решены (ADR-016). Итог — [отчёт о готовности к программированию](architecture/READINESS.ru.md).
- Следующий шлюз: владелец читает и утверждает план, схему, API и модули → разрешение начать Ф0. Реальные проверки — после программирования (условие владельца).

## 4. Открытые вопросы к владельцу

1. Коммерция: цена, выпуск лицензий и оплата отложены владельцем; будущий тариф BYOK со скидкой 50%.
2. Проверки до выпуска: происхождение и лицензии голосов, условия Tavily и MET Norway (ADR-014).
