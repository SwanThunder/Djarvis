Снимок: 2026-11-04, Europe/Moscow, после PLAN-021. Это обзорная сводка; источником истины остаются связанные канонические документы и общий журнал. Обновлять или заменять снимок при существенном изменении статуса.

## 1. Общее состояние

- Этап: проектирование. Кода приложения нет, программирование не разрешено.
- Готово: требования к продукту, обязательный визуальный дизайн (плюс локальные брифы v2.1 и компоновки v1.0), четырнадцать узких ADR и подробные предложения по всем 20 компонентам (CP01–CP20).
- Выполнимость (PLAN-021): локальная модель, синтез речи, собственный PostgreSQL и встроенный Python работают на CPU; память 8 ГиБ впритык — см. [проверки выполнимости](architecture/FEASIBILITY.ru.md).
- Следующий шлюз: финальная архитектура и план реализации на явное утверждение владельца.

## 3. Компоненты: предложенное направление и открытые вопросы

Всё ниже — неутверждённые технические предложения, если не указано в разделе 2.

| Группа | Предложено | Открыто |
| --- | --- | --- |
| Фундамент CP01–CP04 | Локальный HTTP API с потоком событий (альтернатива — named pipe); один Python-процесс владеет записью и базой; типизированные команды с ревизиями | Транспорт, формат сообщений, DDL, версия и поставка PostgreSQL, драйвер, миграции, восстановление после сбоя |
| Логика CP05–CP07 | Детерминированный планировщик; исходное локальное время хранится отдельно от вычисленного; неизменяемые вложения | Разрешение равенства, граница уже начатого блока, размер сегментов и буферы, поля проектов/заметок, часовые пояса и смена часов для таймера, перенос и удаление веток |
| Ассистент CP08–CP11 | Модель предлагает, исполняет типизированный реестр инструментов; одна схема состояний звука; надёжные напоминания | Runtime модели, распознавание речи, wake-фраза, синтез, **лицензии голосов**, производительность CPU/8 ГБ не проверена, паузы проактивности |
| Внешнее CP12–CP14 | Адаптеры провайдеров с локальной очередью; ограниченные разрешения Windows | Провайдеры поиска/погоды и стоимость, детали OAuth, идентификация приложений и проверка аргументов |
| Доверие CP15–CP16 | Архивы AES-256-GCM с ключами под DPAPI; лицензия с подписью Ed25519 | Формат архива, **цена, выпуск лицензий, оплата (отложена)** |
| Поставка CP17–CP20 | Подписанный EXE или MSIX; локальная диагностика без телеметрии | Формат установщика, направление Android (DD10), план тестов и производительности |

## 4. Открытые вопросы к владельцу

1. Коммерция: цена, выпуск лицензий и оплата отложены владельцем; будущий тариф BYOK со скидкой 50%.
2. Проверки до выпуска: происхождение и лицензии голосов, условия Tavily и MET Norway (ADR-014).

## 5. Что осталось

1. Закрыть раздел 4 небольшими порциями вопросов.
2. Оставшаяся выполнимость: распознавание речи и wake-фраза, реальная машина с 8 ГиБ только на CPU, прослушивание Vosk 0.9, проверка фонемизатора под GPL.
3. Технические детали на стороне агентов: транспорт, схема, криптография, миграции.
4. Финальная архитектура и план реализации → утверждение владельцем → программирование.
