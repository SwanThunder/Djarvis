# Djarvis

[English version](README.md)

Djarvis — персональный интеллектуальный помощник для ведения дел и привычек, общения и поиска информации в интернете.

Идёт фаза Ф0 — каркас приложения (разрешена владельцем 2026-11-05, ADR-028). Приняты Flutter для интерфейса, Python для ядра и фоновой логики и управляемый приложением частный PostgreSQL; решения T1–T6, фазы Ф0–Ф7 и критерии их приёмки, архитектура процессов и структура каталогов core/ + ui/ (ADR-022), схема базы, API и модули (ADR-024–026) утверждены. Выполнен шаг 1 [плана Ф0](docs/architecture/P0_PLAN.ru.md): каркас ядра и интерфейса, закреплённые инструменты проверки и CI. Работающего приложения пока нет — есть только каркас.

## Структура

```text
core/             Python-ядро: пакет djarvis_core, тесты, закреплённые зависимости разработки
ui/               Flutter-интерфейс для Windows (пакет djarvis_ui)
scripts/          Скрипты проверки и сборки (check.ps1)
.github/          Проверки CI для запросов на слияние до main
docs/             Правила разработки, проект и согласованные решения
Plan/             Общий журнал разработки на английском и русском
config/           Конфигурация без секретов
assets/           Статические ресурсы
data/
  db/             Локальная папка каркаса; будущий PostgreSQL размещается в %LOCALAPPDATA%
  files/          Локальная папка каркаса; рабочие файлы приложения будут вне репозитория
cache/            Восстанавливаемый кэш
logs/             Журналы работы приложения
tmp/              Временные файлы
```

Полная утверждённая структура каталогов описана в [плане реализации](docs/architecture/IMPLEMENTATION_PLAN.ru.md) §2; остальные части появляются на следующих шагах Ф0 и в последующих фазах.

Папки data/, cache/, logs/ и tmp/ могут содержать локальные материалы подготовки; их рабочее содержимое исключено из выгрузки по правилам проекта. Не очищай их как часть изменения структуры. У установленного приложения частная рабочая база и файлы пользователя располагаются вне репозитория, в профиле Windows. В папке data/db сейчас нет рабочей базы Djarvis.

## Проверки локально

Нужны Windows, Python 3.12 и Flutter 3.47.7. Из корня репозитория в PowerShell:

```powershell
py -3.12 -m venv core\.venv
core\.venv\Scripts\python -m pip install --require-hashes -r core\requirements\dev.txt
core\.venv\Scripts\python -m pip install --no-deps --no-build-isolation -e core
powershell -ExecutionPolicy Bypass -File scripts\check.ps1
```

Скрипт запускает анализ и тесты ядра и интерфейса и останавливается на первой ошибке; ключ `-Build` дополнительно собирает интерфейс для Windows (нужна Visual Studio с компонентом разработки классических приложений на C++). Те же проверки выполняются в CI для запросов на слияние до main.

Репозиторий: [SwanThunder/Djarvis](https://github.com/SwanThunder/Djarvis).

Следующий шаг — шаг 2 [плана Ф0](docs/architecture/P0_PLAN.ru.md): встроенные среды Python и PostgreSQL. GitHub хранит только отправленные файлы и не заменяет резервную копию будущих локальных данных пользователя.
